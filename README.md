## 💻 Featured Projects

### 1. DocuMind — Intelligent Document Organization Assistant

An AI-assisted document processing concept designed to transform uploaded PDFs into structured learning material.

**Highlights**
- Document text extraction and analysis.
- Context-aware quiz generation.
- LLM-powered workflow orchestration.
- Integration work involving Langflow, LangGraph, Groq, and Gradio.

**Technologies:** Python, Gradio, LangGraph, Langflow, Groq.

### 2. ForensicAI — Suspect Visualization Using Latent Diffusion Models

An experimental research project exploring the generation of facial visualizations from natural-language witness descriptions.

**Highlights**
- Text-conditioned image generation using Stable Diffusion.
- CLIP-based text conditioning.
- Experimental facial feature matching using DeepFace, FaceNet512, and VGG-Face.
- Exploration of image-quality evaluation and similarity scoring.

**Technologies:** Python, PyTorch, Stable Diffusion, CLIP, DeepFace, Hugging Face Diffusers, Gradio.

**Research note:** Experimental similarity scores and generated images are not proof of identity and should not be used alone to make forensic or criminal decisions.

### 3. Parkinson's Disease Prediction Using Voice Data

An experimental machine learning project exploring prediction from voice-related features and model interpretability.

**Highlights**
- Fuzzy K-Nearest Neighbors as a modelling approach.
- SHAP-based feature interpretation.
- Exploration of Digital Twin concepts for patient-state monitoring.

**Technologies:** Python, Machine Learning, Fuzzy KNN, SHAP.

*This project is experimental and is not a clinically validated diagnostic system.*

### 4. Hybrid ANN–Random Forest Climate Forecasting

A research-oriented project exploring a hybrid approach to climate forecasting using Artificial Neural Networks and Random Forest.

**Highlights**
- Feature engineering and temporal data splitting.
- Hybrid model exploration.
- Regression-based performance evaluation.
- Investigation of seasonal bias correction.

**Technologies:** Python, Artificial Neural Networks, Random Forest, Machine Learning.

### 5. Todo List REST API — Native Node.js

A backend learning project focused on understanding HTTP request handling and REST API fundamentals without using Express.

**Highlights**
- Native Node.js request handling and routing.
- Task priorities and due dates.
- Overdue detection and sorting.
- API structure and documentation.

**Technologies:** Node.js, JavaScript, REST APIs.

## ⚙️ Run Locally

You can run this project locally without installing a frontend framework.

1. Clone the repository:

   ```bash
   git clone https://github.com/arpitabuilds/Portfolio_arpitaBuilds.git
   ```

2. Open the project directory:

   ```bash
   cd Portfolio_arpitaBuilds/arpita_portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and use a local development server such as Live Server.

**Note:** Keep the asset folders in their expected locations so that images, stylesheets, JavaScript, and PDF links load correctly.

## 🌐 Deployment

This project is hosted as a static website using GitHub Pages.

To deploy updates:

1. Commit and push the updated website files to the configured GitHub branch.
2. Verify that GitHub Pages is configured to publish from the correct directory.
3. Wait for the deployment to complete.
4. Open the live URL and test the updated website.
